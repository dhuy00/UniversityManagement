## 7. PostgreSQL API infrastructure

### Request transaction middleware

```
UniversityManagementAPI/
├── Data/Postgres/
│   ├── IPostgresRequestTransaction.cs    -- Interface for transaction management
│   ├── PostgresRequestTransaction.cs     -- Implements: opens connection,
│   │                                    --   initializes security context,
│   │                                    --   commits on success
│   ├── IAuthenticatedPostgresUser.cs    -- Extracts user ID from HTTP context
│   ├── HttpContextPostgresUser.cs       -- JWT claim: "app_user_id"
│   └── PostgresAuthenticationDataSource.cs
├── Middleware/
│   └── PostgresRequestTransactionMiddleware.cs
│                                        -- Middleware: initializes before endpoint,
│                                        --   commits after success
├── Extensions/
│   └── PostgresServiceExtensions.cs      -- DI registration
└── Repositories/
    ├── PostgresAuthRepository.cs        -- Authentication lookup
    └── PostgresProfileRepository.cs      -- Profile queries (first migrated repo)
```

### DI registration

```csharp
services.AddPostgresRequestInfrastructure(configuration);
// Registers:
// - NpgsqlDataSource (singleton)
// - PostgresAuthenticationDataSource
// - IPasswordVerifier + BcryptPasswordVerifier
// - IAuthenticatedPostgresUser + HttpContextPostgresUser
// - IPostgresRequestTransaction + PostgresRequestTransaction
// - IPostgresAuthRepository + PostgresAuthRepository
// - IPostgresLoginService + PostgresLoginService
// - IPostgresProfileRepository + PostgresProfileRepository
```

### API transaction contract

1. Authenticated request arrives with JWT containing `app_user_id` claim
2. Middleware intercepts and checks for `app_user_id` claim
3. If present: open connection → begin transaction → set security context
4. Repository commands use the same connection/transaction
5. On success: commit transaction
6. On failure: transaction rolled back by disposal

**Critical**: Never accept user ID from client input. Always use the
server-validated claim from the authenticated principal.
